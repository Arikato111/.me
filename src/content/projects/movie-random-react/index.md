## 🚀 Why?

เคยไหมที่อยากดูหนังสักเรื่องแต่ก็เลือกไม่ถูกว่าจะดูเรื่องอะไร
เลื่อนหาไปสิบกว่าหน้าก็ยังไม่มีเรื่องไหนถูกใจ ผ่านไปสิบนาทีก็แล้ว ยี่สิบนาทีก็แล้ว
จะดีกว่าไหมถ้าคลิกไม่กี่คลิก สุ่มเลือกหนังมาสักเรื่อง แล้วก็ไปดู

จุดประสงค์อีกอย่างคือเอาไว้เก็บรายการภาพยนตร์ที่ประทับใจ เพราะเวลาผ่านไปนานๆ ก็ลืม

## Linux คืออะไร?

Linux ก็คือระบบปฏิบัติการหนึ่งที่มีความคล้ายคลึงกับ Unix
โดยปกติแล้วคนทั่วไปจะรู้จักอยู่เพียง Windows ของ Microsoft และ MacOS ของ Apple
Linux มักจะถูกใช้ในสายงานเฉพาะทางมากกว่าใช้ทั่วไปตามบ้าน
ก็เลยไม่ค่อยเป็นที่รู้จักในหมู่คนทั่วๆ ไป

ความพิเศษอย่างหนึ่งของ Linux คือ เป็น **Open Source** นั่นหมายความว่า**มีการเปิดเผย Source code** ซึ่งจะทำให้ใครก็ตามสามารถนำไปพัฒนาต่อยอดได้ (และต้องปฏิบัติตามลิขสิทธิ์)
และประโยชน์สำหรับผู้ใช้งานคือ **ความเป็นเจ้าของ** หากลองยกตัวอย่างเทียบกับ Windows แล้ว
แม้ว่าเราจะจ่ายเงินซื้อ Windows แท้ในราคาหลายพันบาท แต่เราก็ไม่ได้เป็นเจ้าของอย่างแท้จริง
สิทธิ์การปรับเปลี่ยนแก้ไข Windows ยังคงอยู่กับ Microsoft หมายความว่า Microsoft อยากจะปรับจะยัดอะไร หรือถอดฟีเจอร์อะไรออกไปก็ได้ แต่สำหรับ Linux แล้ว เราสามารถปรับเปลี่ยนได้ทุกอย่าง ไม่เพียงแต่การปรับแต่งหน้าจอ Desktop แต่ยังหมายรวมไปถึง Software ทุกอย่างในเครื่อง หรือแม้แต่ Kernel เองก็ตาม ลองคิดดูว่าเราจะถอนการติดตั้ง **Microsoft Edge** ออกจาก Windows ได้หรือไม่ แต่สำหรับ Linux แล้ว ในทางทฤษฎี คุณสามารถถอนการติดตั้งได้แม้กระทั่ง **Kernel**

จริงๆ **Linux** นั่นเป็นเพียง Kernel ซึ่งระบบปฏิบัติการนี้ควรจะถูกเรียกว่า **GNU/Linux** 
แต่อย่างไรก็ดี คนก็เรียกระบบปฏิบัติการนี้ว่า **Linux** อยู่ดี แทนที่จะเป็นชื่อเต็มๆ 
## Linux มีราคา 0 บาท

สิ่งหนึ่งที่คุณควรรู้คือ **Linux** นั้นฟรี ต่างจากระบบปฏิบัติการอื่นๆ ที่คุณต้องจ่ายเงินเพื่อใช้งาน
ด้วยความเป็น **Open Source** ทำให้ **Linux** นั้นฟรี เราไม่ต้องจ่ายเงินแม้แต่บาทเดียวเพื่อใช้งาน
อาจจะสงสัยว่าแล้วผู้พัฒนาอยู่รอดกันได้อย่างไร เขาไม่กินข้าวกินน้ำกันหรอ

ด้วยความที่เป็น **Open Source** นั่นหมายถึงใครจะเข้ามาพัฒนาก็ได้ และใครจะนำไปใช้งานก็ได้
แต่ก็มีผู้ดูแลอยู่ก็คือ **Linux foundation** ซึ่งเป็นองค์กรไม่แสวงผลกำไร หมายความว่ามีรายได้จากเงินบริจาค แต่สาหรับคนที่นำ **Linux** ไปพัฒนาต่อนั้น ก็มีโมเดลการหารายได้ที่ต่างออกไป

### พัฒนาโดยชุมชน

การนำ **Linux** ไปพัฒนาต่อ บางครั้งก็เกิดจาก **ชุมชน** หรือ **กลุ่มคน** ที่ต้องการสร้างสรรค์หรือแก้ปัญหาอะไรบางอย่าง หรือ มีแนวคิดไอเดียที่อยากจะพัฒนา **Linux** ในแบบที่ต่างออกไป
ซึ่งไม่ใช่การแสวงหารายได้ให้มากที่สุดเป็นหลักเหมือนแนวคิดของบริษัท
การพัฒนาโดยชุมชนนั้นก็หมายถึงใครก็สามารถเข้ามาร่วมพัฒนาได้ 
เหมือนกับ**เมือง**ที่ผู้คนร่วมกันสร้าง คนที่เข้ามามีส่วนร่วมอาจจะเป็นคนเก่งๆ ในสักบริษัทโดยใช้เวลาหลังเลิกงาน หรือนักศึกษาที่กำลังเรียนอยู่

### พัฒนาโดยบริษัท

แม้ **Linux** จะฟรี แต่อย่างอื่นไม่ได้ฟรี แม้ตัว **Linux** เองจะนำไปขายตรงๆ ไม่ได้ (เนื่องจากมันฟรี)
ดังนั้นบางบริษัทจึงขายอย่างอื่นแทน เช่น การบริการ (support) เป็นต้นว่าหากคุณใช้งาน Linux ของบริษัทแล้วเกิดปัญหา คุณสามารถติดต่อ Support ได้ หรือคุณอยากได้การปรับแต่งอะไรเป็นพิเศษแต่คุณไม่รู้ต้องทำอย่างไร ต้องแก้โค้ดส่วนไหน ก็ให้บริษัทเป็นคนทำแทน ซึ่งอาจจะมาในรูปแบบของ **Subscription**

### การมีส่วนร่วมของบริษัทหรือองค์กร

บางครั้ง **Linux** ก็ไม่ได้เป็นสินค้าหลักสำหรับการขายเสมอไป 
ในบางองค์กร **Linux** อาจจะเป็นเครื่องมือสำคัญที่ช่วยให้สินค้าของเขาสามารถขายได้
หรือบ้างอาจจะเป็นเครื่องมือสำคัญในการสร้างสินค้าหรือบริการ
ดังนั้นแล้ว ในองค์กรเองก็สามารถมีทีมพัฒนา **Linux** ของตัวเองได้
เช่นว่า บริษัทอาจจะเปิด Cloud server ให้บริษัทอื่นมาเช่าใช้งาน
และใช้ **Linux** เป็นระบบปฏิบัติการหลัก
หรือแม้แต่ผู้ให้บริการด้านเน็ตเวิร์กเองตาม อุปกรณ์ที่เกี่ยวกับเน็ตเวิร์กหลายๆ ตัวก็รันด้วยระบบปฏิบัติการ **Linux**  
เมื่อบริษัทพิ่งพา **Linux** เพื่อขายสินค้าหรือบริการของพวกเขา ก็จำเป็นอย่างยิ่งที่จะต้องทำให้
**Linux** นั้นอยู่รอดต่อไปได้
## Linux Distro

อย่างที่ได้กล่าวไปว่า Linux เป็น Open Source นั่นหมายความว่าใครก็สามารถนำไปพัฒนาต่อได้
จึงทำให้เกิด Linux เวอร์ชั่นต่างๆ ขึ้นมา และมีชื่อเรียกที่แตกต่างกันออกไป โดยมักจะเรียกเวอร์ชั่นต่างๆ เหล่านี้ว่า
**Distro** ซึ่งมาจากคำว่า **distribution** (การแจกจ่าย)
โดยการนำไปพัฒนาต่อนั้นก็เพื่อการแก้ไขปัญหาที่ต่างกันออกไป โดยมีการปรับเปลี่ยนหรือแก้ไข
ให้เข้ากับการใช้งานรูปแบบใดรูปแบบหนึ่ง เช่นว่า การใช้งานใน laptop ราคาไม่แพงที่มีความเร็วค่อนข้างต่ำ ก็จะใช้ Distro หนึ่ง แต่ใน laptop ราคาแพงๆ การ์ดจอแรงๆ ก็จะใช้อีก Distro หนึ่ง

สามารถดู Distro ต่างๆ ได้ที่ [DistroWatch](https://distrowatch.com/)

ลองจินตนาการว่า Linux เป็นเนื้อดิบๆ และการนำไปพัฒนาต่อก็เหมือนการนำไปปรุง
เชฟบางคนอาจนำไปย่าง บ้างอาจจะนำไปทอด ไปผัด ไปตากแดด
และมากกว่านั้น เมื่อเชฟคนหนึ่งย่างเสร็จแล้ว เชฟคนอื่นอาจจะเอาเนื้อย่างไปสับเป็นชิ้นเล็กๆ
และนำไปผัดกับซอสต่อก็ได้ และเชฟอีกคนก็นำผัดนี้ไปคลุกกับเศษอาหารเหลือและนำไปให้หมู
## Destop Environments

ด้วยความว่าเราสามารถติดตั้งหรือถอนการติดตั้ง Software ใดๆ ก็ได้ 
นั้นหมายความว่าเราจะไม้ถูกผูกขาดการใช้งานกับ Software ใด
แม้กระทั่งหน้าจอ Desktop

Destop Environments หรือ DE ก็คือ Software ตัวหนึ่งที่ทำให้ **Linux** มีหน้าตา UI ขึ้นมา
มี Icons มีแถบสถานะ และอื่นๆ เราสามารถเลือกหน้าตาแบบใดก็ได้ที่ต้องการ รวมไปถึงการปรับแต่งเพิ่มเติม
### GNOME

![gnome-desktop](https://firebasestorage.googleapis.com/v0/b/source-54c83.appspot.com/o/source%2Ffor-blog%2Fdebian.png?alt=media)

https://www.gnome.org/

Gnome เป็น DE ที่ผมคุ้นเคยมากที่สุด และใช้งานบ่อยที่สุด เนื่องจากว่าผมเริ่มต้นใช้ 
Linux ครั้งแรกจาก Ubuntu ซึ่งเป็น Linux Distro ตัวหนึ่งที่ใช้ Gnome เป็น DE หลัก
ผมชื่นชอบตัวนี้ที่สุด ด้วยว่ามันตอบโจทย์การใช้งานโดยไม่ต้องปรับแต่งอะไรมาก
มีความเรียบง่าย ไม่มีอะไรยุ่งยาก ซับซ้อน หรือเกินความจำเป็น
### KDE Plasma

![kde-plasma-desktop](https://firebasestorage.googleapis.com/v0/b/source-54c83.appspot.com/o/source%2Ffor-blog%2Ffullscreen_with_apps.png?alt=media)

https://kde.org/plasma-desktop/

KDE Plasma เป็น DE ที่มีความคล้ายคลึงกับ Windows พอสมควร โดยเฉพาะแถบเมนูด่านล่าง
หากเคยชินกับหน้าตาของ Windows ตัวนี้ก็เป็นตัวเลือกที่ไม่เลว
จุดเด่นอย่างหนึ่งของตัวนี้คือ **การปรับแต่ง** 
ในช่วงที่ผมใช้งาน Linux แรกๆ ก็มีช่วงหนึ่งที่ใช้งาน DE ตัวนี้
และปรับแต่งให้มีหน้าตาเหมือนกับ **MacOS** ซึ่งถือว่าเหมือนมาก เหมือนยันอนิเมชั่น
แต่แน่นอนว่าก็แลกมากับการที่ต้องมานั่งปรับแต่งอยู่หลายชั่วโมงกว่าจะได้ 
และอาจจะทำให้หนักเครื่อง เนื่องจากต้องติดตั้งส่วนเสริมเยอะพอสมควร 
### Xfce

![xfce-desktop](https://firebasestorage.googleapis.com/v0/b/source-54c83.appspot.com/o/source%2Ffor-blog%2Fscreenshot-xfce.jpg?alt=media)

https://www.xfce.org/

Xfce ถือเป็น DE ตัวหนึ่งที่เน้นความเบาและประหยัดทรัพยากรเครื่อง เหมาะกับเครื่องที่ไม่แรง
โดยหน้าตาจะค่อนข้างเรียบ ไม่ค่อยมีอนิเมชั่น ผมเคยพยายามใช้งานตัวนี้อยู่เป็นครั้งคราว
ด้วยว่าต้องการประหยัดแรม และ Linux Distro ที่ใช้งานปัจจุบันเลือก Xfce เป็น DE หลัก
แต่สุดท้ายก็กลับไปใช้ Gnome เหมือนเดิม

### อื่นๆ

นอกจากที่ยกตัวอย่างมา ก็ยังมี DE ตัวอื่นๆ อยู่อีกพอสมควร 
แต่อาจจะไม่ได้กล่าวถึงเนื่องจากว่าไม่เคยใช้ ไม่เป็นที่นิยม 
หรือบางตัวจะใช้กับแค่ Linux Distro หนึ่งเท่านั้น ไม่เหมาะใช้กับ Distro อื่น

## LTS or Rolling release

สิ่งสำคัญอย่างหนึ่งที่ต้องรู้ก่อนการใช้งาน Linux แต่ละ Distro ก็คือ **รูปแบบการปล่อยอัปเดต**
หรือก็คือ รูปแบบที่จะปล่อย Software ออกมาให้ผู้ใช้งานได้อัปเดต
ไม่ใช่ว่า Software จะถูกปล่อยออกมาให้อัปเดตเป็นเวอร์ชั่นล่าสุดเสมอไป 
เพราะเวอร์ชั่นล่าสุดอาจจะมีบักหรือข้อผิดพลาดที่สามารถหลุดรอดจากการทดสอบของนักพัฒนาได้
ดังนั้น บาง Software จะมีรุ่นทดสอบ เพื่อปล่อยออกมาให้ทดสอบใช้งานก่อนจะปล่อยอัปเดตให้ผู้ใช้ทั่วไป

LTS หรือก็คือ **Long-Term Support** หมายความว่า มีการซัพพอร์ตระยะยาว 
ทั้งการอัปเดตต่างๆ เพื่อแก้บักหรืออุดช่องโหว่ความปลอดภัย และมุ้งเน้นไปที่ความเสถียร 
โดย Software จะถูกทดสอบให้แน่ใจก่อนจะมีการปล่อยอัปเดต และเมื่อครับกำหนดเวลาแล้ว
ก็จะหยุดการซัพพอร์ต เหมือนกับ Windows 10 ที่สิ้นสุดการซัพพอร์ตในวันที่ 25 ตุลาคม ค.ศ. 2025
ซึ่งจะไม่มีการอัปเดตใดๆ ผู้ใช้จึงควรอัปเดตเป็นเวอร์ชั่นใหม่ 
LTS จะมีประโยชน์มากหากเราต้องการรันเซิร์ฟเวอร์ใดๆ เนื่องจากว่ามีความเสถียร
มากกว่า Rolling release และการซัพพอร์ตที่นานพอให้ไม่ต้องคอยลงระบบปฏิบัติการเวอร์ชั่นใหม่บ่อยเกินไป

Rolling release คือการปล่อยอัปเดตแบบต่อเนื่องที่เราจะได้ Software เวอร์ชั่นใหม่ล่าสุดเสมอ
ซึ่งจะต่างจาก LTS ที่จะมีการอัปเกรดเวอร์ชั่นใหญ่ (อารมณ์เหมือนย้ายจาก Windows 10 ไป Windows 11) โดย Rolling release จะเป็นการปล่อยอัปเดตออกมาเรื่อยๆ แทน
ทำให้เราสามารถใช้งานไปได้เรื่อยๆ แต่ก็มีข้อเสียตรงที่ การอัปเดตเป็นเวอร์ชั่นล่าสุดอาจจะมีบัก
หรือข้อผิดพลาด นอกจากนั้น Rolling release อาจถูกใช้เป็นสนามทดลองก่อนปล่อยเวอร์ชั่นเสถียรให้กับ LTS อย่างไรก็ดี แม้ดูเหมือนจะไม่มีการอัปเกรดใหญ่ (Major upgrade) แต่ความจริงคือ
มันก็มีนั่นแหละ (อย่างน้อยก็ที่ผมเคยใช้) ซึ่งมันก็จะเหมือนการอัปเดตทั่วๆ ไป 
แต่มีโอกาสผิดพลาดมากกว่า ลักษณะคือจะมี Software ถูกปล่อยให้มาอัปเดตมากผิดปกติ
หากโชคดี การอัปเดตก็จะผ่านไปได้ด้วยดีและไม่มีปัญหาการใช้งาน

LTS จะเหมาะกับงานใช้งานที่ต้องการความเสถียรมากๆ เช่น การรันเซิร์ฟเวอร์
ในขณะที่ Rolling release จะเหมาะกับการใช้งานทั่วไปใน laptop หรือ PC ส่วนตัว 
และไม่ควรนำไปรันเซิร์ฟเวอร์เป็นอย่างยิ่ง

## เลือกใช้ตัวไหนดี

ก่อนอื่นผมอยากจะแนะนำให้รู้จักกับ Linux Distro บางตัวก่อน
Linux Distro บางตัวก็เป็นต้นทางของอีกตัว  เป็นต้นว่า B พัฒนาต่อจาก A
กล่าวได้ว่า A เป็นต้นทางของ B
เมื่อเราสืบสาวต้นทางต่อไปก็จะพบกับตัวต้นกำเนิด ในที่นี้จะหมายถึง Independent Linux Disto
ซึ่ง Distro ต้นกำเนิดที่ผมอยากแนะนำให้รู้จักคือ
- Debian - https://www.debian.org/
- Redhat - https://www.redhat.com/en/technologies/linux-platforms/enterprise-linux
- Archlinux - https://archlinux.org/

ด้วยว่า Distro ลูกจะพัฒนาต่อจาก Distro แม่ หมายความว่า นอกจากจะต้องรอ 
Distro แม่ออกอัปเดตก่อนแล้ว Distro ลูกก็จะมีความเหมือนกับ Distro แม่ในหลายประการ
แทนที่เราจะต้องมานั่งไล่ดู Distro ทั้งหมดในโลก ซึ่งมีมากมายเหลือเกิน ก็มาดู Distro แม่แทน
ซึ่งจริงๆ ก็มีมากกว่านี้อยู่ แต่ไม่เหมาะกับผู้เริ่มต้น

### Debian
เป็น Distro ที่ถูกพัฒนาโดยชุมชนและอาสาสมัครจากทั่วโลก 
โดยไม่ได้ถือครองโดยบริษัทที่แสวงผลกำไร
Debian เป็นอีกหนึ่งตัวที่เสถียรมากๆ จากประสบการณ์ที่ได้ใช้งานในรูปแบบ Desktop
ถือว่าเป็นอีกหนึ่งตัวที่ใช้งานยากมาก เนื่องจากว่า Software ที่เน้นความเสถียรขั้นสุด
ทำให้ล้าสมัยขั้นสุดด้วยเช่นกัน Software หลายตัวยังเป็นเวอร์ชั่นเก่า 
และ Software ใหม่บางตัวก็ไม่มีให้ติดตั้งตามปกติ เนื่องจากใหม่เกินไป เลยต้องหาวิธีแปลกๆ ในการติดตั้ง
ถือว่าเป็นตัวที่เหมาะกับ เซิร์ฟเวอร์มากกว่า และไม่เหมาะกับ Desktop เท่าไหร่ (อาจจะลองเวอร์ชั่น Testing หากต้องการใช้บน Desktop จริงๆ )

### Redhat

นี่คือ Distro ที่ถูกพัฒนาโดยบริษัทที่แสวงผลกำไร นั่นหมายถึงเป็น
Linux Distro ระดับ Enterprise เลยทีเดียว นี่ก็ถือเป็นอีกหนึ่ง Distro ที่เน้นความเสถียรมาก
และมีทีมพัฒนาคอยซัพพอร์ต (หากคุณเป็นลูกค้านะ) 
นี่เป็น Linux Distro หนึ่งที่ผมแทบไม่เคยใช้งานเลย เนื่องจากผมหนีมาจาก Windows
ก็เลยมีความเข็ดหลาบจากบริษัท**แสวงผลกำไร**พอสมควร
และมีแนวคิดของการเป็น**อิสระ** แม้ผมจะเคยใช้งานหลาย Distro แต่ผมก็มักจะเลี่ยง
Distro ที่พัฒนาโดยบริษัท แม้จะไม่ได้มั่นใจว่าตนคิดถูก 
แต่หลังจากที่เห็น Redhat ทำกับ CenOS (เป็น Linux Distro ลูกของ Redhat) 
ก็มีความแน่ใจในการตัดสินใจพอสมควร

### Archlinux

Archlinux เป็น Linux Distro ที่เลื่องลือในความใช้งานยาก นั่นหมายความว่าหากคุณใช้งานมันได้
คุณก็จะเป็นคนหล่อเท่ เป็นคนคูลๆ นั่นเอง ความใช้งานยากของมันเริ่มต้นที่การติดตั้ง
โดยคุณจะได้ทำเองทุกขั้นตอน ตั้งแต่การเชื่อมต่อ Usb การ mount การฟอร์แมต Disk
และทำทั้งหมดนี้ด้วยการพิมพ์คำสั่งบนหน้าจอดำๆ และคุณต้องติดตั้งโปรแกรม หรือแม้แต่ Kernel
ด้วยตัวคุณเอง อะไรที่คุณอยากจะใช้ก็จะต้องพิมพ์คำสั่งติดตั้งเอง
ไม่เหมือนกับ Distro อื่นที่จะติดตั้งให้คุณอัตโนมัติ
ข้อดีคือมันจะเบาและเร็วมากกว่าตัวอื่น เนื่องจากคุณติดตั้งเฉพาะ Software 
ที่ต้องการใช้งานเท่านั้น จะไม่มี Software เกินจำเป็นมารันให้เปลืองทรัพยากรเครื่อง
ในปัจจุบันก็มี **archinstall** ที่จะทำให้การติดตั้ง Archlinux นั้นเป็นไปได้ง่ายมากขึ้น
แต่ผมก็ไม่แนะนำอยู่ดี

Archlinux เป็นรูปแบบ Rolling Release ที่มุ่งเน้นไปที่การใช้งานบน PC หรือ laptop ของคุณ
อย่าหาเอาไปรันเป็นเชิร์ฟเวอร์ละ เว้นแต่คุณชอบความตื่นเต้น
### เริ่มต้นที่นี่

เมื่อคุณเลือก Disto แม่ที่คุณพึงพอใจได้แล้ว ก็เหลือแค่มองหา Distro ลูกที่เหมาะ

หากคุณชื่นชอบหรือประทับใจ Debian ผมขอแนะนำ

- [Linux Mint](https://linuxmint.com/download.php) - หน้าตาคล้าย Windows และเหมาะกับ Desktop
- [Ubuntu](https://ubuntu.com/) - หน้าตาเรียบง่าย แต่ควรระวังเพราะพัฒนาโดยบริษัทแสวงผลกำไร

หากคุณชื่นชอบ Archlinux ผมแนะนำ
- [Manjaro](https://manjaro.org/) หน้าตาเรียบง่าย ติดตั้งและใช้งานง่าย

## การติดตั้ง Software

Linux จะมี Software ตัวหนึ่งเป็นตัวหลักของแต่ละ Distro ในการทำหน้าที่ติดตั้ง Software
จาก Repository ของผู้พัฒนา ให้นึกถึง App store หรือ Play store 
ซึ่งเราก็จะมีแอปที่ใช้ติดตั้งแอปอื่นๆ จากสโตร์
สำหรับ Linux แต่ละ Distro ก็อาจมีโปรแกรมที่แตกต่างกันออกไปเช่น
Debian และ Distro ลูก จะใช้ **apt** เป็น Software หลักในการติดตั้ง Software อื่นๆ
ใน Archlinux ก็จะใช้ **pacman** 
### flatpak or snap

นอกจาก **apt** หรือ **pacman** ที่ถูกใช้เป็น Software หลักแล้ว เรายังสามารถติดตั้ง Software ตัวอื่น
ที่สามารถทำการติดตั้ง Software ได้ ก็คือ **Flatpak** และ **Snap**
หากคุณใช้ Linux Mint ก็จะมี Flatpak มาให้ในตัวโดยที่คุณไม่ต้องทำการติดตั้งเพิ่มใดๆ
และหากคุณใช้ Ubuntu ก็จะมี Snap มาให้ 

ในการใช้งาน ทั้งสองตัวนี้สามารถใช้ในรูปแบบ GUI ที่คุณไม่ต้องไปนั่งพิมพ์คำสั่งเหมือน Apt หรือ Pacman และที่ดีกว่านั้นคือมี Software ยอดฮิตพร้อมให้ติดตั้งค่อนข้างมาก

คุณสามารถเข้าดูผ่านเว็บไซต์ได้ดังนี้
- [flatpak](https://flatpak.org/)
- [snap](https://snapcraft.io/store)

 การใช้ flatpak หรือ snap ในการติดตั้ง Software แทนที่จะใช้ apt หรือ pacman
 ถือเป็นตัวเลือกที่ไม่เลว เนื่องจากการใช้ apt/pacman ไม่ใช่เรื่องง่ายนักกับ Software บางตัว
## Linux commands

หากคุณเป็นมือใหม่ และเห็นคนใช้ Linux เปิดหน้าต่างดำๆ และพิมพ์คำสั่งอะไรไม่รู้ยาวๆ 
แล้วก็มีตัวหนังสือมากมายวิ่งไปวิ่งมาบนหน้าจอ คงอาจรู้สึกขวัญผวาไม่น้อย 
และเริ่มเกิดความกังวลในใจว่า "ฉันจะต้องทำแบบนี้ด้วยหรือเปล่า?" คำตอบที่ช่วยให้สบายใจขึ้นคือ
"ไม่จำเป็นครับ" คุณไม่จำเป็นที่จะต้องพิมพ์คำสั่งใดๆ ถึงจะใช้งาน Linux ได้
และเพื่อให้น่าเชื่อถือมากขึ้น บน Windows เองก็มีหน้าต่างดำๆ และคำสั่งเช่นเดียวกันครับ
ใน Linux Distro ที่ถูกปรับให้เหมาะกับผู้ใช้ทัวไป คุณไม่จำเป็นต้องพิมพ์คำสั่งใดๆ

แต่หากคุณเป็นนักเรียนสายคอมแล้วละก็ นี่คือสรวงสวรรค์เลยทีเดียวละครับ 
Linux command ไม่ใช่จุดด้อย แต่เป็นจุดเด่นที่จะทำให้สามารถกระทำการใดเพียงแค่พิมพ์
ลองจินตนาการเล่นๆ ว่าหากต้องลากเมาส์ และกดคลิกซ้ายสัก 100 ครั้งดูสิครับ
คงเมื่อยมือแย่ การแค่กดปุ่มสัก 100 ครั้งก็ดูจะสบายกว่าใช่ไหมละครับ
แต่ที่ดีกว่านั้นคือ เราสามารถแค่พิมพ์คำสั่งเดียว แทนที่จะกดคลิก 100 ครั้งได้ครับ
Linux command ถือเป็นอีกหนึ่งสิ่งที่ทำให้ผมอยู่กับ Linux มาจนถึงทุกวันนี้

## ความปลอดภัย

ในช่วงเข้ามาแรกๆ ผมก็มักจะได้ยินว่า "Linux ปลอดภัยกว่า Windows" อยู่พอสมควร
โดยเฉพาะเกี่ยวกับ virus คอมพิวเตอร์ที่ Windows มักจะป็นตัวโดนมากกว่า Linux
และผู้ใช้งาน Linux อาจโม้ให้คุณฟังว่า เข้าไม่จำเป็นต้องใช้ anti-virus เลย
หากจะพูดว่า Linux ปลอดภัยกว่า Windows ก็อาจจะพูดได้ไม่เต็มปากนัก
ส่วนตัวผมเองนั้นมองว่ามันดูมีความปลอดภัยมากกว่าก็จริง แต่จริงๆ แล้วไม่ได้ต่างกันเลยครับ

หากมองโดยหลักแล้ว Linux จะมีระบบการจัดการสิทธิ์ที่ดูดีกว่าของ Windows
และ Windows มักจะชอบทำอะไรเสี่ยงๆ อย่างเช่น การดาวน์โหลดไฟล์แล้วคลิกรันได้ทันที
ในขณะที่บน Linux ไม่ง่ายแบบนั้น แต่ต้องไปให้สิทธิ์เสียก่อนจึงจะรันได้
แต่ว่ากันตามตรงแล้ว Linux ไม่ได้ปลอดภัยขนาดนั้นเลยครับ ผมมองว่าสาเหตุที่ Windows
ดูเป็นแบบนั้นเพราะมีจำนวนผู้ใช้งานสูงจึงมักตกเป็นเป้าหมายในการสร้าง virus
และเนื่องจากผู้ใช้งาน Windows ส่วนใหญ่เป็นคนทั่วไป ไม่รู้จัก Linux ข่าวเกี่ยวกับ Windows
จึงแพร่หลายมากกว่า ขณะที่ทางฝั่ง Linux เองก็มีเรื่องมีราวเกี่ยวกับช่องโหว่อยู่ไม่น้อย
หากตามข่าวดูก็จะพอทราบบ้างครับ
